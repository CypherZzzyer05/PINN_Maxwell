# 圆偏振激励的分层介质光纤 Maxwell PINN

日期：2026-10-12。分支：`codex/cylindrical-circular-layers`。从已验证的平板波导分支创建独立 Git worktree，按用户选择采用介质芯层与外部包层。

## 几何和分界面

| 区域 | 半径 | 折射率 |
| --- | --- | --- |
| 芯层 | 0 ≤ r < 0.75 μm | 1.60 |
| 内包层 | 0.75 ≤ r < 1.50 μm | 1.45 |
| 外包层 | r ≥ 1.50 μm | 1.44 |

波长 1.55 μm，传播沿 +z，计算圆柱半径 4 μm、长度 10 μm。分层沿径向，两个分界面为半径 0.75 和 1.50 μm 的圆柱面；导出它们在 0≤z≤10 μm 上的完整场，同时给出 z=0 与 z=L 的横截面和界面圆周数据。

各介质无损、各向同性，μr=1，沿 z 不变。外部介质延伸到无穷远，r=4 μm 是计算截断面。导模的精确衰减边界保留包层尾场；这里不是 PEC 金属壁，也不是把场在计算边缘硬设为零。

## 全矢量模式与圆偏振

介质圆柱的混合模式一般同时具有 Ez 和 Hz，界面要求切向 E/H、法向 D/B 连续。[UT Austin 的介质波导推导](https://farside.ph.utexas.edu/teaching/jk1/Electromagnetism/node118.html)说明了这类边界与外部衰减解。Bessel 函数适用于圆柱对称波动方程，参见 [NIST DLMF](https://dlmf.nist.gov/10.73)。

本实现求核心约束的 m=±1 混合模式，默认几何的独立模式匹配在指定 neff 区间只找到一个径向本征值，对应 HE11 基模。时间约定 exp(-iωt)，空间相位 exp(i mφ+iβz)。通过两组正交简并模式叠加：

\[
\mathbf E_c=(\mathbf E_x+i\mathbf E_y)/\sqrt2,\qquad
\mathbf H_c=(\mathbf H_x+i\mathbf H_y)/\sqrt2.
\]

这里下标 x/y 表示两组模式，不是单一向量分量。轴心 Ex=A/√2、Ey=iA/√2、Ez=0，对应等幅正交电场和 π/2 相差；H 与同一 Maxwell 模式一致。不能仅凭“E 和 H 相互垂直”定义圆偏振。旋向通过 `handedness=±1` 选择，明确规定 Ey=i·handedness·Ex，避免观察方向不同引起名称歧义。

严格的局部偏振随位置变化，保留纵向分量与界面效应，输出 Stokes S3/S0 图。薄光纤中的矢量模式在强度与偏振方面可偏离 LP01 标量近似，尤其在表面附近。[Le Kien 等的原始研究](https://arxiv.org/abs/quant-ph/0411131)讨论了这种差别。此处不将整个截面的偏振强制修改成均匀理想圆偏振。

## 网络方程

用 h=Z0H 统一 E/H 的数值尺度。m=+1 的四个实状态为 u,w,p,q，在乘公共空间相位前定义：

\[
E_z=u,\quad h_z=iw,\quad E_\phi=p,\quad h_\phi=iq.
\]

法向分量由 Maxwell 代数约束重建：

\[
E_r=ia,\quad h_r=b,\quad
a=(n_{eff}q-w/(k_0r))/\epsilon_r,\quad
b=-n_{eff}p+u/(k_0r).
\]

各均匀材料层训练以下四个一阶方程：

\[
u'/k_0=(\epsilon_r-n_{eff}^2)q/\epsilon_r+n_{eff}w/(k_0\epsilon_r r),
\]
\[
w'/k_0=(\epsilon_r-n_{eff}^2)p+n_{eff}u/(k_0r),
\]
\[
p'/k_0=-(p+a)/(k_0r)-w,\qquad
q'/k_0=-(q-b)/(k_0r)-\epsilon_r u.
\]

这是全矢量 Maxwell 在同轴、沿 z 不变结构中的对称性约化，不是对三维任意结构训练的网络。芯层与每个有限环形层使用独立坐标 MLP，输出四个状态；neff 也参与优化。采样在 r>0，轴点使用解析正则极限而非除以零。

轴心正则性硬编码：u,w 随 r 消失，p,q 是 r² 的光滑函数，并满足 a(0)=−p(0)、b(0)=q(0)。固定 p(0)=1/√2 消除零解和幅值不确定性，公共相位乘 i 后获得上述圆偏振轴心激励。neff 限制在最大包层折射率与芯层折射率之间，当前搜索核心约束的 m=1 模式，不搜索包层模式或所有角向阶数。

损失为 L=L_PDE+10L_interface+10L_open_boundary。优化使用 Adam，随后 L-BFGS。L-BFGS 阶段对整个损失乘同一常数 10^5，保持物理目标与各项相对权重，以避免低残差时绝对数值容差过早影响优化；历史和验收均记录未缩放损失。

## 介质界面与圆柱边界

界面处约束 u,w,p,q 连续，即 Ez、Hz、Eφ、Hφ 连续。从重建关系直接得到：

\[
\epsilon_r E_r=i(n_{eff}q-w/(k_0r)),\qquad Z_0H_r=-n_{eff}p+u/(k_0r).
\]

因此切向状态连续也保证 Dr 与 Br 连续；验证还会直接检查这些法向量。**Er 可以跳变**，理想无自由面电荷界面满足 Er_outer/Er_inner=ε_inner/ε_outer，而不是强求整个 E 向量连续。所有场导出为同一几何位置的左右材料迹，不使用偏移点近似、平均或抹平跳变。

外包层 γ=k0√(neff²−n_outer²)，纵向分量都采用 K1(γr) 的衰减分支，满足：

\[
f'(R)/f(R)=-\gamma K_0(\gamma R)/K_1(\gamma R)-1/R,\qquad f=u,w.
\]

这是一阶角向导模的精确 Dirichlet-to-Neumann 条件。神经网络的最后有限层与该衰减支匹配，故外部延拓和任意外包层截断半径的条件一致。K0/K1 在训练中通过可微积分求积计算，以便边界对 neff 的梯度能参与优化；其值和梯度独立对照 SciPy，当前配置的求积误差小于所需精度。

z=0、L 为单一前向导模的激励与输出截面，沿 z 的 exp(iβz) 相位保留。直、无损单模传播的模长不随 z 改变；圆柱界面上实场分量仍呈角向和轴向相位分布。

## 验证、输出与限制

独立参考采用 J1/I1/K1 基函数的全矢量界面匹配及本征值根搜索。它不提供训练场标签或 neff 初始化。当前默认几何为三层，匹配矩阵 8×8；更厚、多层结构的参考矩阵可能出现条件数问题，需要稳定散射矩阵或 FEM 对照。

验收检查独立点 Maxwell 残差、neff 与参考复场误差、每个界面的切向 E/H 与法向 D/B、轴心圆偏振、外边界可微性、六分量相位重建。额外用笛卡尔有限差分直接检查 curl E、curl H、div D、div B，而不是只重复网络内部残差。

界面 NPZ 包含完整 θ,z、Cartesian 与柱坐标六分量、内外材料迹；CSV 包含输入和输出面上的全角度复数场与模长。图片展示界面展开图与横截面，完整指标见 [实测报告](fiber_validation_zh.md)。模长为复幅值范数，单位 V/m、A/m；不是某一时刻的实场瞬时模长。Poynting 采用 Re(E×H*)/2。

当前材料沿径向分层并沿 z 不变，因此不包含沿 z 的不同材料接缝、端面反射、自由空间光纤耦合、损耗、弯曲或非同轴缺陷。这些需要另一个传播/散射 worktree。当前模式由对称性精确重建，不能声称解决任意三维光路。
